# Digital Clock

A real-time digital clock built with HTML, CSS, and JavaScript.

## Features
- Live time display updating every second
- Shows day, date, month, and year
- Background: Hagia Sophia, Istanbul — a tribute to the Ottoman Empire 
  and Sultan Muhammad Al-Fateh who conquered Constantinople at age 21

## Tech Stack
HTML | CSS | JavaScript

## What I Learned
- JavaScript Date object
- setInterval for real-time updates
- DOM manipulation to display live data
